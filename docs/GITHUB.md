# GitHub Guide

## Repository setup
```bash
git init
git add .
git commit -m "feat: initial AQI prediction project (RF + PCA + Flask)"
git branch -M main
git remote add origin https://github.com/<you>/Air-Quality-Index-Prediction.git
git push -u origin main
```

## Description (one-liner)
> End-to-end Air Quality Index prediction system using Random Forest and PCA, with a Flask + Bootstrap 5 dashboard, REST API, and batch CSV predictions.
